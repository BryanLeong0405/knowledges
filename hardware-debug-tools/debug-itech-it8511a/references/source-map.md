# IT8511A+ source map(通用串口直连)

本技能以"USB 串口转换器直连 DB9"为通用调用方式,不依赖任何 HTTP 控制服务、
总控台或 EXE 程序。以下资料用于核对协议细节,原始文件仍是事实来源。

## 直连工具(技能自带,自包含)

- `references/it8511a_direct.py` — 直连调试脚本(仅依赖 pyserial):
  26 字节组帧、校验、ACK 解析、实时值解码、CH340 自动探测。
  拷贝到任何装有 pyserial 的机器即可使用,不依赖本项目目录。

## 协议核对资料(设备手册/参考工程)

- `IT8511A/docs/6162930.pdf` — IT8500+ SCPI 协议手册(SCPI 命令与 binary 帧均以手册为准)。
- `IT8511A/docs/reference/IT8511A_reference.pdf` — IT8511A 设备参考手册(DB9 引脚、电平、额定值)。
- `IT8511A/docs/eab538c4....pdf` — IT9000/PV8900 软件手册,仅作界面/流程参考。
- `IT8511A/app/server.py` — 参考实现:其中 26 字节 binary 帧协议(命令表、编码/缩放、
  校验算法)来自实机验证,可作为协议细节的交叉核对来源;但本技能不通过该服务控制设备。

## 维护边界

- 本技能不再维护 HTTP API(`/api/*`)、`IT8511A_Controller.exe`、Web UI、总控台
  等控制链路;涉及这些内容的历史文档仅作参考,不作为技能调用方式。
- 根目录 README/AGENTS 提到的其他设备目录(ADCE7351A、PSP405、TDB1003、摄像头、继电器、
  逻辑分析仪、N31D)在本技能范围外;出现这些目录和对应手册前,不应生成对应设备技能。
- 实机验证过的协议事实(本技能权威来源):
  - CH340 直连 DB9 @ 115200,地址 0,binary 协议可稳定通信(ACK 0x12/0x80)。
  - 身份读回:产品 `0x6A`、序列号 `0x6B` 均正常返回(以设备实际返回为准)。
  - 额定值:150 V / 30 A / 150 W。
  - CC 电流 `0x2A` 写 `10 27 00 00`(10000=1.0A),`0x2B` 读回一致。
